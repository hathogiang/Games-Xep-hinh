# NEON STACK

Trò chơi xếp hình Tetris chạy trực tiếp trên trình duyệt, không cần cài đặt thư viện.

## Cách chơi

Mở `index.html` bằng trình duyệt, sau đó chọn **Bắt đầu chơi**.

- `←` / `→`: di chuyển khối
- `↓`: rơi nhanh
- `↑`: xoay khối
- `Space`: thả khối tức thì
- `P` hoặc `Esc`: tạm dừng / tiếp tục

Điểm số, cấp độ và số hàng đã xóa được cập nhật trong lúc chơi. Kỷ lục được lưu trên trình duyệt hiện tại. Trên điện thoại, sử dụng các nút điều khiển bên dưới bàn chơi.
